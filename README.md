# SHEIN Clone MVC 🛍️

A full-stack e-commerce web application inspired by modern fashion e-commerce platforms. This project is being developed using **ASP.NET Core MVC, C#, Entity Framework Core, SQL Server, HTML, CSS, JavaScript, and Bootstrap**.

> **Project Status: 🚧 In Development**
>
> This project is not yet complete. It is an ongoing learning and portfolio project, and I am continuously adding features, improving the user experience, and refining the application.

## About the Project

The SHEIN Clone MVC project is a fashion e-commerce application created to strengthen my practical software development skills and demonstrate my ability to build a full-stack web application.

The project includes product browsing, product categories, product details, shopping cart functionality, wishlist functionality, order processing, and invoice-related features.

I am building this project from the ground up while developing my understanding of:

* Full-stack web development
* ASP.NET Core MVC architecture
* C# programming
* Database design and management
* Entity Framework Core
* SQL Server
* Object-oriented programming
* Web application architecture
* Git and GitHub version control
